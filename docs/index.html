Blocky AI

강화학습(Afterstate TD 학습)으로 훈련한 AI가 대기 블록 3개를 놓을 순서와 위치를 추천합니다.

블록 선택 (클릭, 최대 3개)

    전체 보기

    사용법

    1. 보드의 삼각형을 클릭해 실제 게임 보드와 똑같이 채웁니다.
    2. 위 목록에서 지금 나온 블록 3개를 고릅니다.
    3. 보드에 표시된 1·2·3 순서대로 두면 됩니다. ◀ ▶ 로 단계별로 보면 지워질 줄이 밝게 표시됩니다.
    4. 추천대로 적용을 누르면 줄 삭제까지 반영되고, 다음 3개를 고를 수 있습니다.

    보드 아래 대기 블록을 클릭하면 선택이 취소됩니다.

    AI 관전 모드

    AI가 무작위로 나오는 블록으로 혼자 게임합니다.
